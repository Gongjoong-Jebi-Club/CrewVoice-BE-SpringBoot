# CrewVoice-Backend

### 커밋 네이밍 규칙

[ 깃모지 | #이슈넘버 ] 간단한 설명

ex: [ ✨ | #5 ] 메인페이지구현

자세한 설명은 이슈에서 작성하면 됩니다.
**커밋내용적는데 너무 신경쓰지 말고 다른데 시간투자하세요.**

| 커밋유형 | 깃모지 | 의미                                                |
| -------- | :----: | --------------------------------------------------- |
| Feat     |   ✨   | 새로운 기능 추가                                    |
| Fix      |   ‼️   | 버그 수정                                           |
| Docs     |   📝   | 문서수정                                            |
| Chore    |   🐛   | 코드 포맷팅, 세미콜론 누락, 자잘한 수정             |
| Refactor |   ♻️   | 코드 리팩토링                                       |
| Comment  |   💡   | 주석 추가 및 변경                                   |
| Rename   |   🚚   | 폴더 파일명 수정 혹은 옮기는 작업                   |
| Remove   |   🔥   | 파일을 삭제하는 작업                                |
| HotFix   |   🚑   | 급하게 치명적인 버그를 수정하느 경우(main작업 허용) |
